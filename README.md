📱 Mobile Calculator App (Full Stack)

A full-stack mobile application that performs calculations and syncs history to a cloud database. It features User Authentication and a server-side logic that automatically retains only the last 10 calculations per user.

🚀 Tech Stack

Frontend: React Native (Expo), React Native Paper

Backend: Node.js, Express.js

Database: Supabase (PostgreSQL)

Authentication: Supabase Auth

✨ Features

User Authentication: Secure Login and Sign Up using Email/Password.

Cloud History: Calculations are saved instantly to the database.

Smart Retention: Backend logic ensures only the last 10 calculations are stored per user (FIFO).

Real-time UI: History updates automatically after every calculation.

Cross-Platform: Runs on Android and iOS (via Expo).

🛠️ Setup & Installation

1. Prerequisites

Node.js installed on your computer.

Expo Go app installed on your phone.

A Supabase project (for database & auth).

2. Backend Setup (Server)

Navigate to the server folder and install dependencies:
```
cd calc-server
npm install
```

Start the server:
```
npx nodemon server.js
```

Server runs on port 3000.

(Note: Ensure your server.js contains your Supabase URL and Anon Key).

3. Frontend Setup (Client)

Navigate to the client folder and install dependencies:
```
cd ../calc-client
npm install
```

⚠️ Important Configuration:
Open screens/CalculatorScreen.js and update the API_URL to your computer's local IPv4 address (not localhost):

// Example (Find yours using ipconfig/ifconfig)
const API_URL = '[http://192.168.1.5:3000](http://192.168.1.5:3000)'; 


Start the mobile app:
```
npx expo start --clear
```

Scan the QR code with your phone using the Expo Go app.

🗄️ Database Schema (SQL)

Run this SQL in your Supabase SQL Editor to create the required table:
```
create table calculations (
  id bigint generated by default as identity primary key,
  user_id uuid not null references auth.users,
  expression text not null,
  result text not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);
```

🧪 Testing Guide
